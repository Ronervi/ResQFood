# ResQFood
Sistema de gestión de excedentes de alimentos que conecta establecimientos gastronómicos con personas interesadas en adquirir alimentos disponibles a un precio reducido.
El objetivo del proyecto es contribuir a la reducción del desperdicio de alimentos, facilitando la publicación y reserva de productos excedentes de restaurantes, panaderías, cafeterías y otros similares.

**Funcionalidades del sistema**
El sistema contempla los siguientes roles y funcionalidades:

USUARIO: registrarse e iniciar sesión, consultar, buscar y filtrar publicaciones disponibles, reservar y cancelar reservas, consultar el historial de reservas, calificar su experiencia.

ESTABLECIMIENTO: gestionar sus publicaciones de alimentos, crear, modificar y eliminar publicaciones, consultar reservas recibidas, confirmar el retiro de los pedidos.

ADMINISTRADOR: gestionar usuarios, aprobar o rechazar establecimientos, administrar las publicaciones del sistema.

**Tecnologías usadas**
Java para el desarrollo de la aplicación.
MySQL para la gestión de la base de datos.
NetBeans IDE para el entorno de desarrollo.
JDBC para la conexión entre Java y MySQL.
Git y GitHub para el control de versiones y alojamiento del código fuente.
UML y DER para el análisis y diseño del sistema.

**Base de datos**
La base de datos del proyecto se denomina 'resqfood' y contempla las siguientes entidades principales:
Usuario.
Establecimiento.
Publicación.
Reserva.
Calificación.
Administrador.
El script SQL se encuntra en el archivo 'ResQFood MySQL.sql'
